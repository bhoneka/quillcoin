Can the hider cheat?+

It is built so that the hider has nothing to cheat with:

  • No code and no coordinate is ever shown to them. The tool handles both.
  • The list was locked before the hunt. Every book's fingerprint was on this page before its round opened, and nothing can be added or swapped afterwards.
  • Every hide is on video, recorded by the tool itself, so there is no choosing what gets filmed. Once a round is open a recording cannot be replaced.
  • The hider's own account cannot redeem.
  • All of it can be read: the tool and the site are open source.

The honest limits. The tool runs on the hider's own computer, so it can make tampering visible but not impossible. And blocking one account does not stop anybody from using another. That is why the recordings, the tool's own log of every run and the source are all public: look at them and judge for yourself.

The technical bits+

Fingerprints. The site never stores a code, only its fingerprint (a SHA-256 hash): a short line of letters and digits that any text can be turned into, and that cannot be turned back. That is how the whole list of books can be public without giving a single code away.

A code is 20 characters long and never contains the letters I, L, O or U, so a 1 is always a one and a 0 is always a zero.

The ledger. Every find is one line in a public list. Lines can only be added, and each one carries the fingerprint of the line before it, so nothing can be changed quietly. The page checks all of it inside your own browser.

Whenever coins are sent to a wallet, the newest fingerprint is written into that Solana transaction, where nobody can edit it, the founder included.

Rounds and numbers. Books are hidden in rounds. When a round opens, its list is closed for good. Coin numbers are drawn at random between 1 and 1000, so a number says nothing about where a book is or when it was hidden.
