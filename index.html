QuillCoin

Signed books hidden in dungeon chests across 2b2t. Find one, redeem the code, own a coin.

Redeem a book

How it works

  1. Somewhere on 2b2t, in an ordinary dungeon chest, there is a written book signed by QuillCoin. Its first page is a code.
  2. Whoever finds the book takes it. It is a bearer item: whoever holds it, holds the coin.
  3. Type the code here. First redemption wins; the book is then spent and becomes a souvenir.
  4. You get one QuillCoin on your ledger. The board below shows every coin the moment it is found.

There are no hints. Nobody knows where the books are — the tool that hides them never shows the code or the coordinates to the person hiding, and every coin's hash is published here before anyone hunts for it, so none can be added later. The hider's own accounts cannot redeem.

Rules

Coins only exist when they are found. Each redemption mints 1 coin to the finder and 0.1 to a public founder wallet — that fee is the founder's only income, and it is visible from the first coin. No presale, nothing is ever sold by the founder, and no price is promised: this is a game reward. If people trade it, that is their doing.
