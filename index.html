HOW IT WORKS

  1. Somewhere on 2b2t, in an ordinary dungeon chest, sits a written book signed by QuillCoin. Page one is a code.
  2. Whoever holds the book holds the coin. Take it. Loot it off someone. It's a bearer item.
  3. Type the code above. First redemption wins. The book is then spent — a souvenir with a public record of who cashed it.
  4. You get one QuillCoin. The list above changes the moment it happens.

RULES

No hints. The tool that hides the books never shows the hider the code or the coordinates: it picks a random point, flies there blind, and the first dungeon it sees is the one. The hider's own accounts can never redeem.

Committed before the hunt. Every coin's hash is published here, timestamped, before anyone looks. Nothing can be added later.

Coins only exist when found. Each redemption mints 1 to the finder and 0.1 to a public founder wallet. That fee is the founder's only income, visible from the first coin. No presale. Nothing is sold by the founder. No price is promised — this is a game reward; if people trade it, that's theirs.

Burned coins stay burned. A book destroyed in a chest never mints. Greyed entries might be gone. That's the hunt.
